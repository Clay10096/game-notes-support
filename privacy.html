游戏笔记 / 隐私政策

你的记录，
如何被保存与使用。

生效日期与最近更新：2026 年 9 月 10 日

核心说明

游戏笔记不设开发者自建账号或服务器，不建立集中式用户资料库，不出售用户数据，不用于广告跟踪。应用仍会在设备上处理游戏记录，并在开启同步时将记录及账号来源标识保存到你自己的 iCloud 私有数据库。平台认证凭证不会通过应用的 iCloud 同步上传。

一、适用范围与联系方式

本政策说明“游戏笔记”应用及其技术支持网站如何处理信息。“我们”指游戏笔记开发者。隐私咨询、信息更正或删除请求，请联系 clay106@icloud.com。本政策不替代 Apple、游戏平台或其他外部服务的隐私政策。

二、可选的平台账号连接

应用本身无需注册，也没有开发者自建用户账号。你可以选择连接游戏平台，以读取游戏库、游玩时间、最近游玩日期、平台信息、每日活动及 PlayStation 奖杯概要等数据。

  • 任天堂：通过系统网页认证，读取账号国家或地区、语言及唯一标识，用于匹配地区数据和识别账号。应用不会读取或保存账号密码。
  • Steam：使用你提供的 Web API Key 和 SteamID64，读取可访问的公开游戏库、累计及最近游玩时间。
  • PlayStation：使用你提供的 NPSSO 完成认证，读取可见的游戏历史、游玩时间及奖杯概要。

应用保存的登录令牌、API Key 和刷新令牌仅保存在当前设备的 Apple 钥匙串中，使用 ThisDeviceOnly 保护，不通过 iCloud 同步，也不发送给开发者。进行认证及请求平台数据时，必要的认证信息会发送到相应平台。断开账号连接会删除该账号对应的本机登录凭证。

为区分多账号记录，应用还会保存平台类型、账号标识、显示标签及游戏来源标识。任天堂账号唯一标识经过 SHA-256 哈希处理；SteamID64 和 PlayStation Account ID 作为来源标识保存。这些来源信息属于游戏记录的一部分，可能同步到你的 iCloud 私有数据库；哈希处理不代表信息已完全匿名。

三、本机保存的信息及用途

应用为管理、展示、整理、同步和备份游戏记录，在设备上保存以下信息：

  • 游戏名称、封面、发行日期、发行平台、游玩平台、来源游戏编号；
  • 游玩时长、首次和最近游玩日期、每日活动、奖杯概要；
  • 游玩状态、版本类型、评分、简评和通关信息；
  • 平台账号来源标识及显示标签；
  • 主页标题、副标题、头像、界面偏好、排序和筛选设置；
  • 同步时间、同步状态、下载的封面缓存，以及你主动导入的 JSON 备份内容。

主要游戏记录保存在应用本地文档目录；界面偏好和同步状态保存在系统偏好存储中；平台认证凭证保存在钥匙串中。你主动填写的简评、头像等内容也可能包含个人信息，请按需要填写。

四、iCloud 同步与图片备份

游戏记录同步默认开启，使用当前 Apple ID 对应的 CloudKit 私有数据库。同步内容包括游戏记录、评分、简评、时长、状态、日期、平台及账号来源等信息，不包括登录令牌、API Key、NPSSO 或刷新令牌等认证凭证。

封面和头像的自动云备份默认关闭。开启后，你手动添加或裁剪的封面及头像会作为 CloudKit 资源上传。自动同步会在游戏内容或已选择备份的图片、头像发生变化时触发。你可以在应用设置中的“iCloud同步”关闭“同步游戏记录”或“自动云备份封面和头像”。

数据保存在你的 iCloud 私有数据库，不上传到开发者自建服务器。Apple 按照其服务规则提供存储与网络处理。关闭上述开关停止相应后续同步或备份，不等于删除已经上传的数据或图片。本节描述的是应用内 CloudKit 同步；设备层面的系统备份由你的 Apple 设置及相关规则决定。

五、外部服务与信息传输

使用相应功能时，应用会直接连接以下服务：

  • Apple CloudKit：同步游戏记录和你选择备份的图片；
  • Apple App Store / StoreKit：加载打赏项目、处理付款及验证交易；
  • 任天堂、Steam、PlayStation：进行账号认证，并读取你授权或平台允许访问的游戏信息；
  • 任天堂各地区商店：你手动查询发行资料及封面时访问；
  • Bing 搜索：你主动匹配游戏资料时，发送游戏名称和平台信息，寻找相应官方商店页面；
  • 远程图片服务器：下载游戏平台返回的封面图片。

服务提供方可能处理 IP 地址、网络信息、请求日志及请求所必需的信息。不同服务及其基础设施可能位于不同国家或地区，具体处理和存储安排由相应服务提供方决定。应用不会把你的简评或完整游戏备份用于广告或营销。

可参阅 Apple 隐私政策、Steam 隐私政策、PlayStation 隐私政策及 Microsoft 隐私声明。任天堂相关规则以登录或地区商店页面展示的当地隐私政策为准。

六、自愿打赏与支付

应用提供“送个蘑菇”“送个龙辉晶”“送个三角力量”三个自愿打赏项目，均为一次性消耗型 App 内购买，不是订阅，不解锁额外功能，也不影响免费使用。实际价格以 Apple 购买界面显示为准。

支付、订单处理和交易验证由 Apple StoreKit 完成。应用依据 Apple 验证后的交易结果显示感谢提示，开发者不会直接取得你的银行卡资料或完整支付账户信息。

七、照片、文件与分享

  • 通过系统照片选择器选择封面或头像时，仅你主动选中的图片会交由应用处理；应用不会扫描或批量读取整个照片图库。
  • 你生成分享图片并选择保存时，应用会请求“仅添加照片”权限。
  • 你可以通过系统文件选择器导入 JSON 备份，也可以导出备份或分享图片。
  • 通过系统分享面板选择接收方时，所选内容会提供给你指定的应用或接收方。应用不会自动发送给联系人或社交平台。

你可以在 iOS 设置中管理照片权限；拒绝保存照片权限不会授权应用读取整个图库。已导出的文件、已保存的图片及接收方持有的副本，需要在对应位置另行管理。

八、未使用的 SDK、权限及跟踪

当前版本没有集成广告、行为分析、营销归因、第三方登录、崩溃统计或用户画像 SDK。平台账号连接使用系统认证与网络能力；主要框架为 SwiftUI、Foundation、CloudKit、StoreKit 2、AuthenticationServices、Security / Keychain、PhotosUI、Photos，以及系统文件选择器和分享面板。

当前版本不使用定位、相机、麦克风、通讯录、日历、健康数据、蓝牙、广告标识符、推送通知、后台录音或后台定位；不开展跨 App 或跨网站跟踪，不投放个性化广告。

九、保留、删除及你的选择

本机记录和设置会为持续提供记录管理功能而保留，云端副本受你的同步设置及 iCloud 数据管理操作影响。当前版本没有为所有记录设置统一的自动到期删除期限。

  • 查看、更正与导出：在应用中查看或编辑记录，并通过 JSON 备份导出自己的数据。
  • 断开平台连接：删除对应的本机认证凭证并停止该连接的后续读取；这不会自动删除此前导入的游戏记录或账号来源信息，也不会删除游戏平台账号。平台侧授权可按相应平台提供的方式撤销。
  • 删除游戏记录：当前版本采用标记删除方式，使记录不再显示在正常列表中，并在同步开启时同步删除状态，以防止记录重新导入。带删除标记的记录及其内容仍可能保留在本机和 iCloud，并非立即彻底清除。
  • 清理本机和云端副本：如需彻底清理，请先断开平台连接、关闭相关同步，并通过系统的应用数据及 iCloud 存储管理功能管理可用的删除选项。单独卸载应用不会自动删除 iCloud 副本，也不保证清除钥匙串凭证；重新同步可能恢复仍在云端的记录。
  • 导出及分享副本：请自行删除文件、照片和其他设备或接收方保留的副本。开发者无法代为删除这些副本或直接访问你的 iCloud 私有数据库。

如需删除方面的操作协助，或想询问、纠正、删除你通过支持邮件提供的信息，请联系 clay106@icloud.com，说明请求范围。请勿发送密码、令牌、API Key 或 NPSSO。

十、技术支持邮件与网站

当你主动发送支持邮件时，开发者会收到你的邮箱地址、邮件内容以及你主动附带的截图或文件，用于回复、排查问题和处理隐私请求。邮件会在处理请求及必要后续沟通期间保留；不再需要时删除，法律要求保留的情况除外。你可以要求删除支持邮件中的个人信息。请仅提供排查所需内容，先遮挡敏感信息。

本技术支持网站及隐私政策页面由 GitHub Pages 托管，没有由开发者添加的广告、统计脚本、跟踪 Cookie 或在线信息提交表单。托管服务 GitHub 可能为提供服务及安全目的处理访问者 IP 地址等技术信息，具体参见 GitHub 隐私声明。点击邮件链接会打开你的邮件应用，仅在你主动发送后开发者才会收到邮件。

十一、信息安全与未成年人

应用利用 Apple 钥匙串的设备限定保护和 CloudKit 私有数据库限制信息访问。请妥善保护设备、Apple ID 及游戏平台账号，避免向他人透露认证凭证。任何存储或传输方式都无法保证绝对安全。

未成年人应在监护人指导下使用平台连接、云同步、分享和打赏功能，并遵守相应平台的年龄及账号规则。若监护人认为未成年人通过支持渠道提供了不适当的个人信息，可以联系开发者处理。

十二、政策更新

功能或数据处理方式发生变化时，我们会更新本页面和顶部日期。涉及重要变化时，会通过应用内适当方式提示，并在需要时请求相应授权。关于本政策的任何问题，请联系游戏笔记开发者：clay106@icloud.com。
