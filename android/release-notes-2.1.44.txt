游戏笔记 Android 2.1.44（90）
发布日期：2026-10-27

本次更新：双击顶栏回到顶部
1. 双击应用内顶栏的标题或空白区域，即可快速回到当前页面顶部。首页顶栏滚动时保持可见，详细、简略和批量选择模式均支持。
2. 详情、设置、筛选、统计、各平台账号同步、错误详情、游戏编辑、平台选择、简评编辑、分享设置与预览、倒计时和使用指南等页面接入。
3. 小组件、折扣和待发售只回顶当前显示页，分别保留各页滚动位置。
4. 返回、完成、保存、同步和头像按钮保留原有点击操作。回顶不清除筛选、不改变选择、不会保存或提交编辑。
5. 增加无障碍“回到顶部”操作。使用系统双击判定规则，离开页面时取消滚动任务。
操作范围为应用内标题栏，不占用 Android 系统通知栏手势。

同时包含：任天堂读取与诊断改进（2.1.43）
1. 识别接口明确返回的 HTTP 590 / 590001 维护错误，显示简明原因和恢复建议，避免误导玩家移除账号或反复登录。
2. 明确维护或限流后停止对该接口重复切换语言、客户端标识和凭证，继续尝试其他可用接口；提前尝试不带地区头的兼容请求。
3. 按接口汇总失败原因，支持一键复制脱敏诊断，不包含凭证、账号标识、响应正文或完整网址。
4. 备用接口的 401 不再将维护误报为登录失效。读取失败保留已有游戏和个人编辑，可用接口返回的数据继续保留。
说明：本版改进应用侧的维护识别、请求控制和诊断；任天堂接口维护仍需官方恢复服务。

同时包含：名称一致性与旧数据保护（2.1.42）
1. 统一 PC / Windows PC、PSP / PlayStation Portable、WiiU / Wii U 等平台别名在输入、保存、回填、详情、筛选、统计和导出中的处理，减少重复选项、漏选和重复计数。
2. 保留 Steam Deck、PlayStation VR2、PlayStation 5 Pro 等自定义平台；游玩平台与发售平台仍独立处理。
3. 修复购买信息回填产生重复空白入口和快速输入金额新增重复记录的问题；已有多笔购买信息完整保留并区分。
4. 统一分类和公司名称的去重规则，区分玩家创建的“未分类”和未填写分类；同名账号分开展示。
5. Xbox 同一游戏的跨账号合并不再受官方可用平台清单差异影响。备份导入检查重复来源和归属冲突，避免重复时长及已删除记录重新出现；冲突时保留本地数据。
6. 保留旧记录、账号来源编号、手动平台修改、时长、评分、购买金额与简评；未编辑的平台字段不作批量改写。
