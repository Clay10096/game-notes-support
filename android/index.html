本次更新

  • 修复 PS 游戏与奖杯列表中 nextOffset 或总数为空时被误判为格式错误的问题，正常末页可以完成读取；分页不完整时仍保留本地数据。
  • 区分登录失效、访问受限和数据读取异常，不再一律提示重新登录。覆盖更新后，可在 PS 账号同步页点击“立即重试”。
  • PS 登录默认使用浏览器，完善获取及粘贴 NPSSO 的流程，并说明 Online ID 是 PSN 公开昵称。
  • 优化 PS 登录页标题和统计数字排版，减少小屏及大字号下的异常换行。
  • 详情页和相关弹窗按实际窗口高度布局，并预留系统导航安全距离，修复部分机型底部内容与保存按钮无法完整滚动到的问题。
  • 折扣卡片取消固定高度，缩短行距和留白；当地价格及人民币参考价完整显示，不再截断。小屏或大字号时自动改为上下排版。
  • 实验功能中的小组件、折扣和待发售分区更清晰；完善倒计时收藏、预览与未知发售日期的处理，倒计时资料现在包含在游戏 JSON/ZIP 备份中。
  • 同平台多账号的同一游戏可合并显示，并保留玩家手动建立的跨平台合并关系；手动修正的总时长在后续同步中继续叠加新增时长。
  • 断开账号后保留已导入游戏与来源关联；重新连接时优先识别原有记录，减少重复卡片。
  • PS 奖杯读取暂时失败时保留上次成功获取的数据；无法确认归属的旧记录不会被冒险自动合并。
  • 游戏折扣卡片在当地币种价格下显示约人民币参考价，并标注汇率日期；实际支付金额以官方商店和支付渠道为准。
  • 应用内“获取最新版本”改由新网站提供更新信息；旧网站继续提供更新入口，供此前安装的版本使用。

PS读取仅为试验性功能，稳定性待验证。

游戏记录与倒计时资料保存在本机，建议定期导出备份。桌面小组件的跨日刷新可能受系统省电策略影响而延迟，不保证午夜整点刷新；不同桌面上的显示仍需实机验证。人民币价格为参考估算，实际支付金额以官方商店和支付渠道为准。

安装提醒

  • 已安装 1.7.5 或更新的正式签名版本，可直接覆盖安装；请勿卸载，以保留本机数据。
  • 1.7.4 及更早测试版使用不同签名，不能直接覆盖。先在旧版中导出完整备份并核实文件，再卸载旧版、安装正式版和导入备份。登录凭证不在备份中，需要重新连接账号。
  • 此页提供 APK 下载，不代表应用会在后台自动安装；请核对浏览器显示的下载来源。
